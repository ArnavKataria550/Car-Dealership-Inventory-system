# Car Dealership Inventory System

A full-stack web application for managing a car dealership's vehicle inventory.

## Tech Stack

| Layer    | Technology                                                              |
| -------- | ----------------------------------------------------------------------- |
| Backend  | Node.js, TypeScript, Express                                            |
| Database | PostgreSQL via Prisma ORM                                               |
| Frontend | React, Vite, Tailwind CSS                                               |
| Testing  | Vitest + Supertest (backend), Vitest + React Testing Library (frontend) |

## Status

🚧 Early development — the project is being built in small, incremental steps.
